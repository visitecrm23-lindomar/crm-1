## 1.1. STACK TECNOLÓGICA OBRIGATÓRIA

### Frontend:
- Next.js 14+ (App Router, Server Components, Server Actions)
- TypeScript (strict mode)
- Tailwind CSS + shadcn/ui (Radix UI)
- React Hook Form + Zod
- TanStack Query (React Query)
- Zustand (state management)
- @dnd-kit/core (drag & drop Kanban)
- Recharts (gráficos e dashboards)
- Tiptap (editor de texto rico)
- @react-pdf/renderer (geração de PDFs)
- qrcode (geração de QR codes)
- date-fns (manipulação de datas)
- Lucide React (ícones)
- react-dropzone (upload de arquivos)

### Backend:
- Next.js 14+ API Routes / Route Handlers
- Prisma ORM 5+ (PostgreSQL)
- NextAuth.js v5 (autenticação)
- BullMQ + Redis (filas e jobs)
- Resend (envio de emails)
- AWS S3 ou Cloudflare R2 (storage)
- @upstash/ratelimit (rate limiting)
- Winston (logs)

### Banco de Dados:
- PostgreSQL 15+ (principal)
- Redis 7+ (cache e filas)

### Infraestrutura:
- Replit Deployments ou Vercel
- Neon PostgreSQL (serverless)
- Upstash Redis (serverless)
- AWS S3 ou Cloudflare R2 (storage)
- Cloudflare (CDN)
- Sentry (monitoring)

model Tenant {
  id                String    @id @default(cuid())
  name              String
  slug              String    @unique
  subdomain         String?   @unique
  custom_domain     String?   @unique
  
  // Contato
  email             String
  whatsapp          String?
  phone             String?
  
  // Endereço
  address_street    String?
  address_number    String?
  address_city      String?
  address_state     String?
  address_zipcode   String?
  address_country   String?   @default("Brasil")
  
  // Branding
  logo_url          String?
  primary_color     String?   @default("#3B82F6")
  secondary_color   String?   @default("#10B981")
  
  // Plano e Status
  plan_id           String
  plan              Plan      @relation(fields: [plan_id], references: [id])
  status            String    @default("trial") // trial, active, suspended, cancelled
  trial_ends_at     DateTime?
  subscription_id   String?
  
  // Limites
  limits            Json      // { users: 10, clients: 5000, trips: 100, storage_gb: 50 }
  
  // Configurações
  settings          Json?
  
  // Timestamps
  created_at        DateTime  @default(now())
  updated_at        DateTime  @updatedAt

  users             User[]
  clients           Client[]
  trips             Trip[]
  reservations      Reservation[]
  products          Product[]
  orders            Order[]
  payments          Payment[]
  messages          Message[]
  automations       Automation[]

  vehicles          Vehicle[]
  accommodations    Accommodation[]

  referrals         Referral[]
  destinations      Destination[]
  
  @@index([slug])
  @@index([subdomain])
  @@index([status])
}

## 2.1. 📊 DASHBOARD (PAINEL CENTRAL)

**Rota:** `/dashboard`

### Funcionalidades por Role:

#### 🏢 Dashboard Agência:

**Cards de KPIs (4 principais):**
- Total de Clientes (com variação % do mês anterior)
- Receita Total (soma de todos os pagamentos confirmados)
- Viagens Ativas (status: open, confirmed, in_progress)
- NPS Médio (média dos últimos 30 dias)

**Gráficos:**
1. **Receita vs Despesas** (últimos 6 meses)
   - Linha verde: Receita
   - Linha vermelha: Despesas
   - Área sombreada: Lucro

2. **Origem dos Clientes** (Pizza/Donut)
   - Instagram
   - WhatsApp
   - Indicação
   - Google
   - Facebook
   - Outros

// Ao mover card entre colunas
const handleDragEnd = async (result) => {
  if (!result.destination) return
  
  const clientId = result.draggableId
  const newStage = result.destination.droppableId
  
  // Atualizar no banco
  await updateClientStage(clientId, newStage)
  
  // Registrar no log de auditoria
  await createAuditLog({
    action: 'pipeline_move',
    resource: 'client',
    resource_id: clientId,
    metadata: {
      from: result.source.droppableId,
      to: newStage
    }
  })
  
  // Disparar automação (se configurada)
  await triggerAutomation('pipeline_stage_changed', {
    client_id: clientId,
    new_stage: newStage
  })
}

const updateClientSeat = async (clientId, seatNumber) => {
  // 1. Atualizar reserva do cliente
  await prisma.reservation.update({
    where: { client_id: clientId },
    data: {
      seats: {
        push: seatNumber
      }
    }
  })
  
  // 2. Atualizar mapa de assentos da viagem
  await prisma.trip.update({
    where: { id: tripId },
    data: {
      seat_map: {
        [seatNumber]: {
          client_id: clientId,
          status: 'reserved',
          client_name: client.name
        }
      }
    }
  })
  
  // 3. Broadcast via WebSocket para outros usuários
  io.emit('seat-updated', {
    trip_id: tripId,
    seat_number: seatNumber,
    client_name: client.name,
    status: 'reserved'
  })
}

### Regras de Cálculo:

**Tipos de Comissão:**

1. **Percentual Fixo:**
   - Exemplo: 5% sobre o valor da venda
   - Cálculo: `valor_venda * (percentual / 100)`

2. **Valor Fixo:**
   - Exemplo: R$ 50,00 por venda
   - Cálculo: `valor_fixo`

3. **Escalonada (por faixas):**
   - Exemplo:
     - Até R$ 5.000: 3%
     - R$ 5.001 a R$ 10.000: 5%
     - Acima de R$ 10.000: 7%
   - Cálculo progressivo por faixa

**Momento de Geração:**
- Ao criar reserva (status: pendente)
- Ao confirmar pagamento (status: aprovada)
- Ao pagar comissão (status: paga)

**Regras de Cancelamento:**
- Se reserva cancelada → comissão cancelada
- Se pagamento estornado → comissão estornada

// public/sw.js

const CACHE_NAME = 'visitecrm-v1'
const urlsToCache = [
  '/',
  '/dashboard',
  '/clients',
  '/trips',
  '/communication',
  '/offline',
  '/manifest.json',
  '/icon-192.png',
  '/icon-512.png'
]

// Instalação
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then((cache) => cache.addAll(urlsToCache))
  )
})

// Ativação
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((cacheNames) => {
      return Promise.all(
        cacheNames.map((cacheName) => {
          if (cacheName !== CACHE_NAME) {
            return caches.delete(cacheName)
          }
        })
      )
    })
  )
})

// Fetch (estratégia: Network First, fallback para Cache)
self.addEventListener('fetch', (event) => {
  event.respondWith(
    fetch(event.request)
      .then((response) => {
        const responseClone = response.clone()
        caches.open(CACHE_NAME)
          .then((cache) => cache.put(event.request, responseClone))
        return response
      })
      .catch(() => caches.match(event.request))
  )
})

// Push Notifications
self.addEventListener('push', (event) => {
  const data = event.data.json()
  
  const options = {
    body: data.body,
    icon: '/icon-192.png',
    badge: '/badge-72.png',
    data: data.url,
    actions: [
      { action: 'open', title: 'Abrir' },
      { action: 'close', title: 'Fechar' }
    ]
  }
  
  event.waitUntil(
    self.registration.showNotification(data.title, options)
  )
})

// Notification Click
self.addEventListener('notificationclick', (event) => {
  event.notification.close()
  
  if (event.action === 'open') {
    event.waitUntil(
      clients.openWindow(event.notification.data)
    )
  }
})

// Background Sync
self.addEventListener('sync', (event) => {
  if (event.tag === 'sync-messages') {
    event.waitUntil(syncMessages())
  }
})

async function syncMessages() {
  // Sincronizar mensagens offline
  const messages = await getOfflineMessages()
  for (const message of messages) {
    await sendMessage(message)
  }
}

// components/pwa/InstallPrompt.tsx
'use client'

import { useState, useEffect } from 'react'
import { Button } from '@/components/ui/button'

export function InstallPrompt() {
  const [deferredPrompt, setDeferredPrompt] = useState<any>(null)
  const [showPrompt, setShowPrompt] = useState(false)

  useEffect(() => {
    window.addEventListener('beforeinstallprompt', (e) => {
      e.preventDefault()
      setDeferredPrompt(e)
      setShowPrompt(true)
    })
  }, [])

  const handleInstall = async () => {
    if (!deferredPrompt) return

    deferredPrompt.prompt()
    const { outcome } = await deferredPrompt.userChoice
    
    if (outcome === 'accepted') {
      console.log('PWA instalado')
    }
    
    setDeferredPrompt(null)
    setShowPrompt(false)
  }

  if (!showPrompt) return null

  return (
    <div className="fixed bottom-4 left-4 right-4 bg-white p-4 rounded-lg shadow-lg z-50">
      <div className="flex items-center justify-between">
        <div>
          <h3 className="font-bold">Instalar VisiteCRM</h3>
          <p className="text-sm text-gray-600">
            Adicione à tela inicial para acesso rápido
          </p>
        </div>
        <div className="flex gap-2">
          <Button variant="ghost" onClick={() => setShowPrompt(false)}>
            Depois
          </Button>
          <Button onClick={handleInstall}>
            Instalar
          </Button>
        </div>
      </div>
    </div>
  )
}
