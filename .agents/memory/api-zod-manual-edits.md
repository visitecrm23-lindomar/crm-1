---
name: api-zod manual edits
description: How to safely add fields to the generated api-zod schemas when orval is not re-run
---

The lib/api-zod package is generated by orval but NOT regenerated on each change. When adding new trip fields:

1. Edit `lib/api-zod/src/generated/types/trip.ts` — TypeScript response type
2. Edit `lib/api-zod/src/generated/types/createTripBody.ts` — TypeScript create type
3. Edit `lib/api-zod/src/generated/types/updateTripBody.ts` — TypeScript update type
4. Edit `lib/api-zod/src/generated/api.ts` — Zod schemas for both `CreateTripBody` and `UpdateTripBody` zod.object() definitions

**Why:** The package exports `./src/index.ts` directly (no build step). Routes use the Zod schemas for runtime validation. If you update the TS types but not the Zod schema, the route will silently strip the new field.

**How to apply:** Any time a new optional trip column is added, do all 4 edits atomically. Search for the last added field (e.g., `layoutId`) to find the right insertion points.
